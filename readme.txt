== Installation ==

1. Install Mortar Example from Plugins → Add New, or upload the zip under Plugins → Add New → Upload Plugin, then activate it.
2. Go to Settings → Mortar Example.

== Frequently Asked Questions ==

= Where is the source? =

The development repository, including the build tools, is [on GitHub](https://github.com/Mortar-Digital/wordpress-plugin-template). The minified script is built from `assets/front.js`, and the settings screen is built from `admin/`.
